Point Cloud Studio
==================

실행
  터미널에서 이 폴더로 이동한 뒤 ./run.sh 실행.
  Python 3.10 이상과 NumPy, PyQt5, VTK가 필요합니다 (requirements.txt 참고).
  run.sh는 Linux의 /usr/bin/python3을 사용합니다.
  다른 Python 환경에서는 해당 환경에 패키지를 설치한 뒤 python3 viewer.py를 실행하세요.
  그래픽 데스크톱 세션에서 실행해야 합니다.

  기본 폴더: 앱 폴더 내 data (초기에는 비어 있습니다).
  파일을 넣으면 이름순으로 첫 파일을 엽니다. 빈 폴더에서는 파일 열기/폴더 변경을 사용하세요.
  다른 폴더: ./run.sh --root "/데이터/폴더"
  파일 지정: ./run.sh "/데이터/파일.bin" (PLY / PCD도 가능)
  다른 Python 환경: python3 viewer.py --root "/데이터/폴더"
  필요한 패키지는 requirements.txt 참고.
  run.sh는 glxinfo로 OpenGL 연결을 확인하고 실패 시 Mesa 소프트웨어 렌더링을 사용합니다.
  소프트웨어 모드 강제: POINT_CLOUD_STUDIO_RENDER=software ./run.sh
  하드웨어 모드 강제: POINT_CLOUD_STUDIO_RENDER=hardware ./run.sh
  소프트웨어 모드는 점 수가 많으면 회전 속도가 느려질 수 있습니다.

사용법
  왼쪽 파일 클릭 / 포인트 클라우드 열기 / 파일 드래그로 읽습니다.
  BIN / PLY / PCD를 파일 목록과 열기, 드래그 모두에서 지원합니다.
  파일명이나 상위 폴더명으로 검색할 수 있습니다.
  왼쪽 드래그: 회전. 휠: 확대/축소.
  가운데 드래그 또는 Shift+드래그: 이동.
  F: 현재 표시점에 화면 맞춤. Ctrl+O: 파일 열기.
  입체 / 위 XY / 정면 XZ / 측면 YZ 버튼으로 방향을 바꿉니다.
  기본 평행 투영을 해제하면 원근 투영이 됩니다.

측정 도구 (뷰포트 위 공통 도구 모음)
  탐색: 화면을 조작합니다. Shift+클릭으로 길이 측정도 가능합니다.
  길이 (2점): 버튼을 누른 뒤 표시된 점 2개를 일반 클릭합니다.
    P1/P2 위치, XYZ 좌표, 직선 거리와 ΔX/ΔY/ΔZ를 표시합니다.
    중복점/수치적으로 구분하기 어려운 점은 설명과 함께 거부합니다.
    기존 첫 점을 유지하므로 다른 두 번째 점을 다시 고르면 됩니다.
  평면 찾기: 현재 표시점에서 주요 평면들을 자동으로 검출합니다. 아래 설명 참고.
  자동 원 검출: 원형 윤곽을 자동으로 찾습니다. 아래 설명 참고.
  측정 초기화 / Esc: 선택점, 검출 후보와 강조 표시를 지우고 진행 중 검출을 취소합니다.
  길이 측정 완료 후 다음 유효한 클릭은 새 측정을 시작합니다.
  도구 변경, 새 파일 읽기, 표본 재읽기, Z 범위 적용 시 이전 검출/측정을 지웁니다.
  Shift+클릭은 길이 (2점) 측정 단축 조작입니다.
  측정 모드에서도 드래그 회전/Shift+드래그 이동/휠 확대는 그대로 사용할 수 있습니다.
    드래그는 측정점을 추가하지 않습니다. 점을 못 고르면 확대해서 다시 클릭하세요.
  모든 측정/검출은 현재 표시 중인 표본점 및 Z 범위 기준입니다.
  계산은 float64로 수행하지만 원본 BIN 좌표는 float32입니다.
  물리 단위는 알 수 없습니다. 지름/길이/허용 거리/잔차는 원본 좌표 단위입니다.
  결과와 좌표 텍스트는 마우스로 선택하여 복사할 수 있습니다.

주요 평면 찾기
  1. BIN / PLY / PCD 파일을 열고 필요하면 Z 범위로 분석할 영역을 좁힙니다.
  2. 뷰포트 위 '평면 찾기'를 누릅니다. 점을 클릭할 필요가 없습니다.
  3. 오른쪽 '검출된 평면 후보' 목록에서 원하는 평면을 고릅니다.
     기본 최대 5개 후보를 포함 점 수 순서대로 표시합니다.
  4. 민트색으로 강조된 점, 노란 투영 범위, 기준점 C와 분홍색 법선 화살표를 확인합니다.
     노란 외곽선은 선택점의 평면 투영 범위를 감싸는 사각형이며 실제 표면 경계가 아닙니다.
     면을 채우거나 원본 점을 이동시키지는 않습니다. PNG 저장에 강조 표시가 포함됩니다.

  설정 (변경 후 다시 검출)
    허용 거리: 점에서 추정 평면까지의 최대 수직 거리. 0=자동.
      자동값은 분석 표본의 가장 큰 XYZ 범위 × 0.002 (0.2%)입니다.
      작게 하면 더 엄격한 평면을, 크게 하면 더 넓은 근사 영역을 찾습니다.
    최소 점 비율: 현재 유효 표시점 중 해당 평면에 포함되어야 하는 최소 비율.
      기본 5%. 최소 30점도 필요합니다. 작은 면을 찾으려면 비율을 낮추세요.
    최대 평면 수: 반환할 후보 수의 상한. 기본 5, 설정 범위 1~10.

  표시값
    점 수/비율: 현재 유효 표시점 전체에 대해 분류한 해당 평면의 점 수와 비율.
    기준점 C와 단위 법선 n: 평면식 n·(X-C)=0을 정의합니다.
      법선의 부호는 최대 절댓값 성분이 양수가 되도록 정합니다. 물체 외향 방향의 보증은 아닙니다.
    RMS: 해당 점들의 평면 수직 거리 제곱 평균의 제곱근.
    최대 편차: 수직 거리의 절댓값 최댓값. 허용 거리 이내여야 합니다.
    잔차 폭: 부호 있는 수직 거리의 최댓값-최솟값.
      RMS/잔차 폭은 평탄도 참고 지표이며 최소영역법의 공인 평탄도 측정값이 아닙니다.

  동작과 범위
    최대 12만 점의 결정적 표본에 RANSAC/최소제곱 맞춤을 적용한 뒤,
    현재 유효 표시점 전체를 허용 거리 안의 가장 가까운 후보 평면으로 분류합니다.
    한 점은 한 후보에만 포함됩니다. 통계는 분류된 전체 표시점을 기준으로 계산합니다.
    화면 강조는 후보당 최대 20만 점으로 제한하되 점 수/잔차 통계는 전체 분류점 기준입니다.
    법선 차이 2도 이내, 평면 기준점의 수직 차이 허용 거리 2배 이내인 중복 후보는 제외합니다.
    같은 평면 위에서 서로 떨어진 영역이 한 후보가 될 수 있습니다.
    곡면도 허용 거리 내에 있는 일부 영역은 근사 평면 후보가 될 수 있습니다.
    구/원통/곡면 재구성이나 화면 확대 영역만 검출하는 도구는 아닙니다.
    선/중복점/지지점이 부족한 입력은 설명과 함께 실패 처리합니다.
    '평면 검출 취소', Esc 또는 초기화로 취소합니다.
    길이 측정 시작, 파일/Z 범위 변경 시 진행 중 결과와 이전 후보를 무효화합니다.
    평면 찾기와 자동 원 검출은 하나씩 실행하며 새 도구는 이전 결과를 초기화합니다.
    PLY/PCD 내보내기는 현재 표시점 전체를 저장합니다. 선택 평면만 따로 저장하지 않습니다.

자동 원 검출
  1. 파일을 열고 필요하면 Z 범위로 원형 구멍/테두리가 있는 표면을 좁힙니다.
  2. 뷰포트 위 '자동 원 검출'을 누릅니다.
  3. 오른쪽 '검출된 원 후보'에서 후보를 선택합니다. 최대 5개 후보를 찾습니다.
     링의 안쪽/바깥쪽 윤곽은 별도 후보로 나올 수 있습니다.
  4. 민트색 원/중심 O, 노란 지름선, 주황색 지지 윤곽점을 확인합니다.
     하단과 뷰포트에 지름/반지름/중심, 3D RMS 잔차, 검출된 호 범위를 표시합니다.

  오른쪽 설정: 허용 오차 / 최소 지름 / 최대 지름. 모두 원본 좌표 단위입니다.
    0은 자동 설정입니다. 숫자를 바꾼 뒤 다시 '자동 원 검출'을 누르세요.
    허용 오차를 크게 하면 더 불규칙한 윤곽도 후보가 될 수 있습니다.
    최소/최대 지름으로 원하는 구멍이나 외경 후보만 제한할 수 있습니다.
  분석 대상은 화면 방향과 무관한 현재 표시 표본 및 Z 범위입니다.
    화면 확대만으로 분석 영역이 줄어들지는 않습니다.
    그중 최대 20만 점을 일정한 난수 시드로 표본화하여 분석합니다.
  PCA로 주된 평면 방향을 구하고 격자 윤곽을 추출한 뒤 RANSAC과
    3D 평면 내 최소제곱 맞춤으로 원을 추정합니다. 수평/수직/기울어진 평면 지원.
    기본 허용 오차는 투영 폭/256 × 1.6, 최소 후보 반지름은 격자 6칸입니다.
    120도 이상의 호와 연속적인 윤곽 지지가 필요합니다.
    결과의 3D RMS 잔차는 허용 오차 이하여야 하며 반지름의 2.5% 이하여야 합니다.
  평면에 가까운 원형 윤곽/구멍을 위한 추정 도구입니다.
    원통/구의 직경 측정이나 여러 방향의 표면을 동시에 분리하는 도구는 아닙니다.
    짧은 호, 가려진 윤곽, 타원, 심한 노이즈에서는 실패하거나 다른 후보가 나올 수 있습니다.
    적합도 조건을 만족하는 원이 없으면 이유를 표시합니다.
    표본화와 격자 윤곽 처리로 오차가 생기므로 결과와 주황색 지지점을 확인하세요.
    RMS는 맞춤 잔차이며 실제 치수에 대한 보증 오차나 신뢰 확률이 아닙니다.
  검출은 별도 작업 스레드에서 진행합니다. '검출 취소', Esc, 측정 초기화로 취소합니다.
    길이 측정/평면 찾기 시작, 파일 변경/Z 범위 적용은 진행 중 검출과 이전 후보를 무효화합니다.

PLY / PCD 읽기
  PLY: ASCII, binary_little_endian, binary_big_endian 지원.
    vertex의 scalar x/y/z와 선택적 red/green/blue 또는 r/g/b를 읽습니다.
    정점의 normal/기타 scalar 속성과 면 정보는 표시/저장하지 않습니다.
    vertex 자체의 list 속성은 지원하지 않으며 설명을 표시합니다.
  PCD 0.7: ASCII, little-endian binary, LZF binary_compressed 지원.
    FIELDS/SIZE/TYPE/COUNT를 해석하고 x/y/z를 읽습니다.
    32비트 packed rgb/rgba (F/U), 또는 별도 색상 채널을 지원합니다.
    normal/descriptor 등 부가 필드는 건너뜁니다. VIEWPOINT 변환은 적용하지 않습니다.
  색상 채널의 정수값은 0~255, 실수 채널은 0~1로 해석합니다.
    rgba의 알파는 사용하지 않습니다. 색상 없는 파일은 기본 회청색을 사용합니다.
    색상이 없으면 파일 정보에 'RGB 없음 (기본색)'을 표시합니다.
  PLY/PCD 좌표는 float64로 유지하며 임의의 단위 변환을 하지 않습니다.
    임시 디스크 파일에 정규화하여 통계/표본 처리를 하므로 전체 좌표를 RAM에 올리지 않습니다.
    큰 파일은 임시 저장 공간과 읽기 시간이 필요합니다. 읽기 취소 시 임시 파일을 정리합니다.

대용량 표시와 통계
  기본적으로 최대 100만 점을 표시합니다.
  원본 레코드 전체를 검사하고 유효점의 순서상 균등한 표본을 추립니다.
  최대 점 수를 변경하면 원본을 다시 읽습니다. '전체 유효점'은 표본 추출을 하지 않습니다.
  유효점 수와 XYZ 범위는 표본이 아니라 전체 유효 좌표의 통계입니다.
  '현재 화면의 점 수'는 표본 및 Z 범위 조건을 모두 적용한 개수입니다.
  NaN / Inf 좌표는 항상 제외합니다.
  (0,0,0)은 미측정 값으로 추정되어 기본 제외합니다. 체크를 해제하면 포함합니다.
  좌표 중 일부가 0인 점이나 Z=4인 점은 임의로 제거하지 않습니다.
  Z 범위를 변경하면 표시할 표본을 자릅니다. 경계는 소수점 4자리 정밀도입니다.
  표시 색상: Z/X/Y 값, 원본 RGB 또는 단색. 좌표 색상 범례는 전체 유효점 범위입니다.

저장
  '표시 점 → PLY / PCD 저장…'에서 파일 형식을 선택합니다.
    PLY: binary_little_endian XYZ + RGB. PCD: binary XYZ + packed RGB.
    좌표가 float64이면 64비트로 저장하여 정밀도를 유지합니다.
    현재 표시하는 점만 저장합니다 (최대 점 수 및 Z 범위 적용).
    화면의 높이별 색상이 아니라 읽은 RGB를 저장합니다. 색상 없는 입력은 기본색을 저장합니다.
    원/지름선/지지점 강조는 PLY/PCD에 포함되지 않으며 PNG에서 확인할 수 있습니다.
    부가 필드, 메쉬 면, 입력의 organized 배열/VIEWPOINT는 보존하지 않습니다.
    전체 유효점을 저장하려면 '전체 유효점'과 '전체 Z 범위 복원'을 먼저 선택하세요.
  PNG: 현재 3D 뷰와 좌표축/색상 범례, 측정 도형/점 이름/결과를 저장합니다.
       도구 모음과 하단 한국어 결과란은 포함하지 않습니다.
  읽기와 검출은 원본 파일을 변경하지 않습니다. 내보내기는 지정한 경로에 저장합니다.

지원하는 BIN 구조
  헤더: big-endian uint32 2개 (가로, 세로), 총 8바이트.
  포인트: little-endian float32 X,Y,Z + uint8 R,G,B, 점당 15바이트.
  파일 크기 = 8 + 가로 × 세로 × 15.
  위 구조와 크기 규칙에 맞는 파일만 지원합니다. 임의의 BIN 파일 전체를 지원하지 않습니다.
  물리 단위 정보는 헤더에 없습니다. mm 등으로 단정하지 않고 원본 좌표 단위를 유지합니다.
  좌표 변환, 카메라 간 정합, 보정, 이상점 자동 제거는 수행하지 않습니다.

파일
  viewer.py: PyQt5 / VTK GUI.
  cloud_io.py: BIN/PLY/PCD 읽기 경로, 표본 추출, PLY/PCD 출력.
  point_formats.py: PLY/PCD 헤더/좌표/색상 및 PCD LZF 압축 처리.
  auto_circle.py: 자동 원형 윤곽 검출과 후보 적합도 계산.
  measurements.py: 길이 측정점 검증과 자동 원 결과 자료형.
  surface_detection.py: 주요 평면 자동 검출, 표시점 분류와 잔차 통계.
  tests/test_measurements.py: 길이 측정점 검증 테스트.
  tests/test_surface_detection.py: 평면 방향/다중 평면/잡음/점 분류/퇴화 입력/취소 테스트.
  tests/test_auto_circle.py: 자동 검출, 내/외경, 부분 호, 비원형 입력과 취소 테스트.
  tests/test_point_formats.py: PLY/PCD 변형, 압축, 좌표/RGB 보존, 잘린 파일, 취소 테스트.
  run.sh: Linux 실행 파일.
  requirements.txt: 다른 환경에서 사용할 패키지 목록.
